## 구성
| 파일 | 설명 |
| :--- | :--- |
| `index.html` | 메인 페이지 (드롭다운 내비게이션 + 10개 섹션) |
| `styles.css` | 다크/골드 럭셔리 테마, 반응형 |

## 보기

# http://localhost:8000
